# fnm + Corepack Setup Guide

This guide explains how to configure your shell for automatic Node.js and package manager switching when working with multiple Creevey examples.

## Prerequisites

- [fnm](https://github.com/Schniz/fnm) - Fast Node Manager
- [corepack](https://nodejs.org/api/corepack.html) - Node.js package manager manager (included with Node 16+)

## Quick Start

Once set up, simply `cd` into any example directory:

```bash
cd esm-vite-sb9
# fnm automatically switches to Node 20
# corepack automatically uses npm
npm install    # works immediately
npm run storybook

cd ../playwright-esm-vite-sb10-bun
# fnm automatically switches to Node 22
# corepack automatically uses bun
bun install    # works immediately
bun run storybook
```

## Shell Configuration

### 1. fnm Auto-Switching (Required)

Add to your shell config (`~/.zshrc`, `~/.bashrc`, or `~/.config/fish/config.fish`):

**Zsh/Bash:**
```bash
# fnm setup
eval "$(fnm env --use-on-cd)"

# Enable corepack on directory change
_fnm_cd_hook() {
  if [[ -f .nvmrc ]] && command -v corepack &> /dev/null; then
    corepack enable 2>/dev/null || true
  fi
}
add-zsh-hook chpwd _fnm_cd_hook  # For zsh
# OR for bash:
# export PROMPT_COMMAND="_fnm_cd_hook; $PROMPT_COMMAND"
```

**Fish:**
```fish
# fnm setup
fnm env --use-on-cd | source

# Enable corepack on directory change
function _fnm_corepack_hook --on-variable PWD
  if test -f .nvmrc; and type -q corepack
    corepack enable 2>/dev/null
  end
end
```

### 2. One-Time Setup Commands

Run these once in your terminal:

```bash
# Install required Node versions
fnm install 20
fnm install 22

# Enable corepack globally
corepack enable

# Verify setup
fnm list
corepack --version
```

## How It Works

1. **fnm** detects `.nvmrc` files on directory change and switches Node versions automatically
2. **corepack** reads the `packageManager` field from `package.json` and routes commands accordingly
3. No manual switching needed - just `cd` and use your package manager commands

## Project Configuration

Each project has:

| File | Purpose |
|------|---------|
| `.nvmrc` | Specifies Node version for fnm |
| `packageManager` in `package.json` | Specifies package manager for corepack |

### Example Configurations

**npm projects (Node 20):**
```json
{
  "packageManager": "npm@10.9.0",
  "engines": { "node": ">=20.0.0" }
}
```
`.nvmrc`: `20`

**pnpm project (Node 20):**
```json
{
  "packageManager": "pnpm@9.15.0",
  "engines": { "node": ">=20.0.0" }
}
```
`.nvmrc`: `20`

**Yarn PnP project (Node 20):**
```json
{
  "packageManager": "yarn@4.6.0",
  "engines": { "node": ">=20.0.0" }
}
```
`.nvmrc`: `20`

**Bun project (Node 22):**
```json
{
  "packageManager": "bun@1.2.4",
  "engines": { "node": ">=22.0.0" }
}
```
`.nvmrc`: `22`

## Available Package Manager Commands

Once configured, use these commands in any project:

| npm | pnpm | yarn | bun |
|-----|------|------|-----|
| `npm install` | `pnpm install` | `yarn install` | `bun install` |
| `npm run <script>` | `pnpm run <script>` | `yarn <script>` | `bun run <script>` |
| `npm test` | `pnpm test` | `yarn test` | `bun test` |
| `npx <pkg>` | `pnpm dlx <pkg>` | `yarn dlx <pkg>` | `bunx <pkg>` |

## Troubleshooting

### "corepack: command not found"
Ensure you're using Node 16+ and run:
```bash
corepack enable
```

### "packageManager not found"
The project may not have `packageManager` field set. Check with:
```bash
rtk read package.json | grep packageManager
```

### fnm not auto-switching
Verify your shell config includes `--use-on-cd`:
```bash
eval "$(fnm env --use-on-cd)"
```

### Package manager version mismatch
Corepack may prompt about version mismatches. Accept with:
```bash
corepack install
corepack use <manager>@<version>
```
